# 文档站视觉走查

本轮于 2026-10-11 对照 [Rspress 首页](https://rspress.rs/zh/)与[介绍页](https://rspress.rs/zh/guide/start/introduction)，检查 [LuLu 线上站点](https://bosens-china.github.io/lulu-for-vue/)和本地工作区。线上版本与已有未提交改动不同，以下修复均落在本地，尚未发布。

## 视觉判断

主要差距在整套文档界面的阅读秩序。首页之外，头部导航的按钮式选中态、偏淡且过小的说明文字、重复容器和代码标签装饰，让页面仍显得像通用后台模板。Token 将组件变量与大量全局变量混排，增加了查找成本。参照 Rspress 的阅读层级，统一外壳、正文与参考表格，保留现有 Vue + Vite + Markdown 架构及组件默认主题。

| 区域 | 走查发现 | 本轮处理 |
| --- | --- | --- |
| 首页 | 组件预览的光晕偏重；整屏最小高度把特性区推到下一屏；安装命令与主要入口挤在一起。 | 减弱光晕与阴影，突出品牌标题，安装命令独占一行，使用内容驱动的首屏高度；缩短文案并移除过时组件数量及无法验证的性能承诺。 |
| 头部与导航 | 头部导航呈现按钮式选中态；搜索、链接与工具缺乏明确分区；侧栏装饰和计数分散注意力。 | 统一品牌、搜索、导航、工具的顺序；头部用文字标识当前章节，侧栏使用轻底色和稳定行高，移除计数徽章；保留筛选与 aria-current。 |
| 布局 | 本地顶部进度条占据正常文档流；内外容器共用正文类名并嵌套两个 main。 | 进度固定在顶部；区分布局容器与正文；每页保留一个 main；正文最大宽度 760px。 |
| Demo | 卡片和说明层级偏重；背景切换是模拟按钮；首页提示调用没有有效的消息宿主。 | 减少阴影和说明背景，使用原生按钮；接入站点消息宿主，在 setup 中获取消息 API。复制源码保留按钮自身反馈。 |
| 正文与 API | 说明字号与灰度偏弱，类型被渲染成许多蓝色代码标签，自动列宽挤压默认值。 | 正文采用独立阅读字体和文字颜色；桌面正文 16px，API 14px、代码 13px；使用横向分隔和无背景代码，分别安排说明、类型和默认值列宽。Markdown 表格放入保留原生 table 的可聚焦滚动区域，手机提示左右滑动。 |
| CSS Tokens | 组件变量和全局变量在一张长表中等权排列。 | 40 个主组件文档分为组件/家族变量和默认折叠的全局基础变量，原有 Token 行、用途和明暗默认值完整保留；使用原生 details/summary。 |
| 深色 | 页面、卡片与代码背景接近纯黑，层级不够清楚。 | 分离页面、预览与代码的中性表面，减少对高亮主色和阴影的依赖。 |
| 手机导航 | 点击筛选输入框也会关闭抽屉；手写抽屉缺少完整的模态焦点管理；目录按钮被默认最小宽度撑大。 | 复用 LuLuDialog；只在选择导航链接后关闭；验证标题聚焦、Escape 与焦点还原；明确目录按钮尺寸。 |
| 主题切换与搜索 | 图标按钮继承实心按钮的悬停、按下背景；长搜索描述撑宽 Grid 内容，导致输入与关闭按钮被裁切。 | 通过实例 CSS Token 指定中性背景和无按压阴影；搜索 Grid 允许收缩，结果改为标题、描述两行，方向键选择时滚动到可见位置。 |
| 全局主题入口 | 调色盘只提供主色，用户需要到各组件页面查找全局变量。 | 主题指南列举 41 项全局变量及用途、明暗默认值；调色盘按分组筛选、预览全部变量，支持非法值提示、恢复和复制 CSS。编辑区保留默认主题，避免预览导致无法操作。 |

## 验证

| 检查 | 结果 |
| --- | --- |
| 40 个组件页 + 4 篇指南，1440×960 | 全部有正文标题、唯一 main，无页面级横向溢出。 |
| 平板，768×1024 | 抽查 4 篇指南、Form 与 DataTable，无页面级横向溢出。 |
| 同上，390×844 | 同上；宽表格与代码在各自区域滚动。 |
| 视觉抽查 | 首页、Button、DataTable、安装指南；检查桌面、平板、手机，以及首页和 Button 的亮色/深色层级。 |
| 浏览器交互 | 手机筛选不误关导航，输入为 16px；Escape 关闭后焦点返回触发器；Token summary 支持 Enter 展开，表格区域聚焦后方向键可横向滚动。此前已检查目录跳转、搜索 Enter 选择、源码展开、首页轻提示。 |
| 全局主题与搜索复查 | 明暗模式分别覆盖并恢复颜色、圆角；非法值保留上次有效设置，编辑区不受预览影响；复制 CSS 成功。搜索框与调色盘在 390px 手机宽度无内容裁切，指南展示完整 41 项变量。 |
| 自动化 | 文档相关 26 个测试文件、81 项测试通过；文档类型检查、相关 ESLint、客户端及 SSG 构建通过。覆盖 SSG 表格可访问性、全局 Token 清单、变量校验、明暗隔离、恢复、CSS 导出与搜索键盘滚动。 |

## 边界

- 全页尺寸检查不等同于逐个操作所有组件、所有状态；本轮不重做组件库的 API 与行为审计。
- 浏览器验证使用本机 Chromium 环境，没有覆盖真实 iOS Safari 或 Firefox。
- 路由懒加载由另一轮并行工作负责，本轮仅随整站构建复查其集成结果。
- 调整没有新增依赖，也没有改变组件包的公开 API 或默认主题。
